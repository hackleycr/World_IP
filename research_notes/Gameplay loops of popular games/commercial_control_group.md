# Gameplay Loops of Broadly Popular Commercial Games (Control Group)

Research date: 2026-10-20. Scope: about 20 popular titles across genres, to compare against systemic, sandbox and discovery games. The end use is a 2D systemic sandbox built on three ideas: reward in proportion to effort (insight over grind), permanent world change, and rule discovery.

**Method caveat.** steamcharts.com, steamdb.info and en.wikipedia.org could not be reached from the research environment (DNS failure, 2026-10-20). As a result:
- Live concurrent-player numbers, current Steam review scores and Wikipedia sales tables could not be pulled directly.
- Quantitative signals below come from press and aggregator reports that cite SteamDB, Steam Charts, AppMagic or Sensor Tower. Each carries the date the source reported.
- Many figures are 2024–2025 vintage. Treat any number not dated 2026 as stale for an October 2026 snapshot.

## Q1. Which loop structures produce engagement that lasts years, and which produce short spikes?

### Takeaway
The loops that last for years share two traits. First, the core action is a skill contest or a fresh-state session (CS2, League of Legends, Dota 2, Fortnite, Clash Royale), or it can be played without end (Candy Crush, Stardew Valley, Skyrim with mods). Second, the reward does not run out: it is mastery, rank or new content, not a power curve with a ceiling.

Short spikes follow a different pattern. Games whose main loop is collecting or building toward a finite power or content ceiling peak early and then lose about 90% or more of their PC concurrent players within months:
- Palworld: –97% in about 3 months.
- Helldivers 2: –90% in about 4–5 months.
- Destiny 2 after The Edge of Fate: –91% within a year.

Seasonal resets (Diablo IV) turn these spikes into a recurring sawtooth rather than steady retention.

### Inferences

#### Per-game loop breakdowns (analyst-derived)
These breakdowns are my design analysis, not sourced claims. Quantitative anchors are cited above.

Schema: core action → immediate feedback → resource/reward → spend/invest → new capability → back to the core action. Time scale; dominant effort type.

| Game | Core → feedback → reward → spend → new capability | Time scale | Dominant effort |
|---|---|---|---|
| Fortnite | Drop, loot, fight → eliminations and placement → XP, Battle Pass tiers → cosmetics only → none in-match (fresh state each match) → requeue | 20-min match; 10-week season | Skill + time (pass) |
| League of Legends | Lane, farm, fight → gold and kills → in-match items → build → in-match power spike; out of match, LP/rank → requeue | 25–35-min match; yearly ranked season | Skill + insight (draft/macro) |
| Counter-Strike 2 | Round: aim, utility, positioning → kill/round win → economy money → buy weapons → round power; Premier rating; cases (RNG cosmetics) | 1–2-min round; 40-min match | Skill + insight (economy, map knowledge) |
| Dota 2 | Like LoL, with deeper item and denial systems; no out-of-match power at all | 40-min match | Insight + skill |
| Elden Ring | Explore and fight → death or victory → runes → level/upgrade → beat the boss and open new areas → explore | Hours per region; 60–100 h finite | Skill + discovery; grind is optional (rune farming as a skill substitute) |
| Skyrim | Explore, quest, use skills → skill-use XP → loot and perks → crafting and enchanting → power → explore | Open-ended | Time + discovery; low skill |
| Stardew Valley | Farm, mine, socialize → harvest, chime → gold and items → seeds, tools, buildings → farm expansion and Community Center bundles that permanently change the town | In-game day ~14 min; seasons; ~50–150 h | Time + planning/insight |
| Hades | Room combat → reward choice → boons (in-run), Darkness/keys/gems (persistent) → Mirror of Night, weapons, keepsakes → stronger runs plus story beats → next run | 20–40-min run | Skill, with persistent unlocks that soften it |
| Vampire Survivors | Move → automatic attacks and gem pickups → level-up choices and gold → PowerUps (refundable) → unlocks and evolutions → next run | 30-min run | Insight (evolution recipes) + time (gold) |
| Balatro | Play a poker hand → chips × mult score → money → jokers/vouchers in the shop → synergy engine → next blind; stakes and deck unlocks | 20–40-min run | Insight (combinatorics) + risk |
| Slay the Spire | Card combat → damage/block → card/relic rewards → deck building and pathing → deck synergy → next floor; Ascension 1–20 | 45–60-min run | Insight + skill; few persistent unlocks |
| Diablo IV | Kill → loot showers → gear, Paragon → crafting/tempering/masterwork → higher Pit/Torment tiers → kill; seasonal reset | Minutes per dungeon; ~3-month season | Time/grind + RNG |
| Destiny 2 | Shoot → loot → power level and god-roll weapons → infusion/build → higher activities → shoot; expansions and sunsetting | 10-min strike; ~1-year expansion | Time + skill (raids) |
| Genshin Impact | Explore/combat → chests and primogems → gacha wishes → characters/weapons, plus resin-gated levelling → stronger team, new region → explore | Daily resin cycle; 6-week patch | Time + money + RNG |
| Candy Crush Saga | Swap → cascade "juice" → stars and progress → boosters and lives (paid) → pass the level → next level | 1–3-min level; daily sessions | Light insight + RNG; paid friction |
| Clash Royale | Deploy cards → tower damage → trophies and chests → card upgrades → stronger deck, higher arena → match | 3-min match | Skill + time/money (card levels: "pay-to-progress") |
| Among Us | Tasks and deduction → votes and ejections → win/lose (no persistent power) → cosmetics → social metagame | 10-min match | Social insight |
| Baldur's Gate 3 | Explore, talk, tactical combat → dice outcomes and reactivity → XP, loot, story flags → builds → new options; the world changes permanently from choices | ~75–150 h finite | Insight + systemic experimentation |
| Helldivers 2 | Mission (co-op chaos) → extraction → samples, medals, requisition → ship modules, Warbonds, stratagems → harder difficulties; persistent Galactic War map | 15–40-min mission | Skill + time; capped currencies |
| Palworld | Capture, build, automate → base output → materials, Pals → tech tree and base → automation → exploration | Hours; ~40–80 h until the tech tree is exhausted | Time + light insight |

#### Patterns
- **Multi-year loops reset state each session.** CS2, LoL, Dota 2, Fortnite, Clash Royale and Among Us return the player to roughly zero power each match. Progression lives in skill, rank or cosmetics. CS2 reaching a record in its 13th franchise year is the strongest evidence that this kind of loop does not go stale.
- **Spikes come from finite power and content ceilings.** Palworld and Destiny 2 (and seasonal Diablo IV) share a "build up power or collection until it is exhausted" loop. Once the tech tree or gear ceiling is reached, the reason to return is gone. Helldivers 2 is a mixed case: its persistent community war map is a "permanent world change" hook, but its PC drop was made worse by an external platform controversy.
- **Big premium single-player games sell over many years.** Elden Ring, BG3, Stardew and Skyrim keep selling, but no single player plays any of them indefinitely. Their "years" come from re-plays, mods and new buyers, not from endless loops.
- **A 2D systemic sandbox can take either route:**
  - Stardew-style permanent town change gives a satisfying, finite arc.
  - CS/Dota-style insight depth (combinatorial knowledge that doesn't run out) gives indefinite engagement.
  - Rule discovery is closest to the Dota/Balatro/Slay the Spire insight loops, whose reward is understanding rather than stats.

## Q2. What are the most common player complaints about reward-per-effort fairness (grind, RNG, pay-to-win, FOMO)?

### Takeaway
The recurring complaints are:
- **Value or progress taken away.** Nerfed or "harder to acquire" best-in-slot items (Diablo IV Season 14), progression or power systems redesigned so earlier effort is devalued (Destiny 2 Edge of Fate), and seasonal resets.
- **Gated or redundant repetition.** Per-class Ascension climbs in Slay the Spire, Paragon grind in Diablo IV, resin and gacha gates in Genshin.
- **Monetization in the progression path.** Genshin gacha, card levels in Clash Royale, Candy Crush boosters and lives.
- **Platform friction outside the loop entirely** (Helldivers 2 PSN).

### Cited Findings
- **Diablo IV Season 14** ("Season of Death Awakening", launched 30 June 2026):
  - Its Mythic Uniques 3.0 rework made former best-in-slot items "weaker and harder to acquire".
  - Blizzard issued a hotfix on 17 July 2026 after three weeks of complaints. GameSpot headlines say Blizzard justified the mythic changes on grounds of long-term game health.
  - Sources: [DiabloBytes](https://www.diablobytes.com/diablo-iv/news/); [GameSpot](https://www.gamespot.com/diablo-iv/)
- **Diablo IV Season 14 on Linux:** the season also broke the game on Linux/SteamOS (Proton), and the first hotfix did not fix it. — [GamingOnLinux](https://www.gamingonlinux.com/2026/07/diablo-iv-season-14-broke-the-game-on-linux-steamos-blizzard-working-on-a-fix/page=1/)
- **Diablo IV Paragon grind:** a Steam forum thread (Season 7, early 2025) defends Paragon 300 as "grindy on purpose", since "normal players aren't meant to reach" it in a season. — [Steam Community](https://steamcommunity.com/app/2344520/discussions/0/597393727567221195)
- **Diablo IV, effort mismatch the other way:** a streamer cleared the Lord of Hatred Torment 12 tier in about 17 hours, against a marketed "weeks-long grind" (April 2026). — [DiabloBytes](https://www.diablobytes.com/diablo-iv/news/2026-04-29-diablo-4-streamer-pulverizes-new-lord-of-hatred/)
- **Destiny 2:** changes to power progression and the Portals system in Edge of Fate were cited as reasons for the decline. Leadership admitted the progression changes "sounded great on paper but didn't work". — [Hitmarker](https://hitmarker.net/news/destiny-2s-latest-expansion-failed-to-meet-player-expectations-director-admits-1586995); [Gameluster](https://gameluster.com/destiny-2-hits-lowest-steam-player-count-ever-as-reviews-plummet/)
- **Slay the Spire:**
  - Players call the per-character Ascension climb "extremely tedious" and "unnecessary grind". One player points to another roguelike that linked its progression after feedback.
  - Another player wants challenge-based rather than grind-based unlocks.
  - Sources: [Steam Community](https://steamcommunity.com/app/646570/discussions/0/1692659769943408705); [Steam Community](https://steamcommunity.com/app/646570/discussions/0/6722218992173007839/?ctp=3)
- **Helldivers 2:** the PSN account requirement led to delisting in more than 175 countries and to refund requests. It is a major cited cause of the PC decline. — [HotHardware](https://hothardware.com/news/helldivers-2-has-lost-90-of-its-pc-players)
- **Genshin Impact:** revenue swings of –73% month-on-month (February 2025) track gacha banner appeal. This shows that monetized RNG makes engagement and spending depend on the banner schedule (FOMO). — [Sportskeeda](https://sportskeeda.com/esports/genshin-impact-reportedly-faces-massive-revenue-drop-february-2025)
- **Palworld:** the developer pushed back on "dead game" framing and endorsed taking breaks. In effect, a finite loop was accepted as finite. — [Automaton](https://automaton-media.com/en/news/20240215-27211/)

### Inferences
- **Fairness complaints focus on loss and devaluation more than on effort size.** Players accept very long grinds (Paragon 300, Ascension 20) when they are optional and permanent. They revolt when past effort is wiped or devalued: seasonal resets, nerfs to best-in-slot items, power-progression redesigns, sunsetting.
  - This favours the user's "permanent world change" pillar. Effort should leave lasting marks.
- **RNG plus money (gacha, Clash Royale card levels, Candy Crush lives and boosters) earns a lot but breeds resentment.** RNG without money (Balatro, Slay the Spire) is read as challenge rather than unfairness.
- **Repetition complaints come from redundancy.** In Slay the Spire, players resent being made to repeat equivalent proofs of skill (the same climb per class) more than they resent difficulty.

### Gaps
- No systematic Steam review mining (e.g. keyword frequencies for "grind" or "p2w") was possible.
- No sourced data was found on:
  - Clash Royale pay-to-win complaints or revenue.
  - Candy Crush monetization complaints.
  - Fortnite Battle Pass FOMO sentiment.
  - Genshin resin complaints (beyond general knowledge, which is not cited here).
- No Diablo IV Steam concurrent figures for 2026 were found.

## Q3. How do roguelite meta-progression loops (Hades, Vampire Survivors, Balatro, Slay the Spire) balance skill/insight against persistent unlocks?

### Takeaway
The four games sit on a range from mostly insight to mostly persistent power. The best-reviewed, most design-respected designs keep persistent unlocks as breadth, tutorial or narrative, and leave power to skill and insight.

| Position | Game | How persistence works |
|---|---|---|
| Insight end | Slay the Spire | Meta-unlocks act as a "gradual tutorial" and run out quickly; Ascension adds difficulty, not power |
| Insight end | Balatro | Unlocks add jokers, decks and stakes (breadth, not stats) |
| Middle | Hades | Darkness/Mirror of Night gives real persistent power, but it is bundled with narrative progress and opt-in Heat difficulty |
| Persistent-power end | Vampire Survivors | Gold buys stat PowerUps; these are refundable, so risk-free |

### Cited Findings
- **Hades loop structure:** the analysis describes a short inner loop (room → reward → next choice) inside longer meta arcs (weapon upgrades, keepsakes from gifts, Mirror of Night). It also describes "skill, investment and narrative delays": players learn enemy patterns over deaths while upgrades take time to pay off. — [Mechanics of Magic, "Loops and Arcs in Hades" (Nov 2025)](https://mechanicsofmagic.com/2025/11/04/loops-and-arcs-in-hades/)
- **Hades Darkness:** Darkness is a persistent currency spent at the Mirror of Night, so "failed runs still contribute to long-term progress". — [games.gg (DE)](https://games.gg/de/hades/)
- **Hades' influence:** a review credits Hades with solving the "narrative meets roguelike" pain point. It says later games (Vampire Survivors, Returnal) absorbed the "meta-progression plus characterized dialogue" template. — [GameGeeker](https://gamegeeker.com/games/hades/review?market=US)
- **Slay the Spire Ascension:** there are 20 Ascension levels, each unlocked by winning the previous one. Ascension works as a long-term "tutorial" pacing tool that keeps the core loop the same while extending lifespan. — [hamatti notes](https://notes.hamatti.org/Gaming/Video-games/Meta-progression-with-gradual-tutorial-in-roguelike-games); [Twinfinite](https://twinfinite.net/?p=336281)
- **Slay the Spire meta-progression:** one commenter says Slay the Spire "has very limited meta progression which is quickly exhausted and basically works as a tutorial". — [lemm.ee comment](https://next.lemm.ee/comment/14156553)
- **Vampire Survivors PowerUps:** gold spent on PowerUps can be fully refunded "as many times as you want, so there's no risk in buying these upgrades". — [Steam Community](https://steamcommunity.com/app/1794680/discussions/0/4631482569784832721)
- **Balatro's commercial result:** an insight-heavy design with breadth-only unlocks reached more than 5 million sales (2025, single source) as a solo-developer game. — [GamesMarket](https://www.gamesmarket.global/publishing/poker-roguelike-balatro-sells-more-than-five-million-copies-311dcc58f214ad4dd53243ae1161ba71)

### Inferences
- **Two kinds of persistent unlock:**
  - Breadth or knowledge unlocks (new cards, jokers, characters, story) widen the space players learn to master. These are the right fit for "insight over grind".
  - Power unlocks (Mirror of Night, Vampire Survivors PowerUps) make the game easier and act as an accessibility floor, so effort eventually wins even with less skill.
  - Hades softens power unlocks with narrative and with opt-in difficulty (Heat), which takes difficulty back on demand.
  - Vampire Survivors makes power refundable, so it can be re-specced without loss and never feels like wasted grind.
- **Suggested pattern for a 2D sandbox built on rule discovery:**
  - Make discoveries (rules, recipes, interactions) the persistent unlock, which matches Balatro and Slay the Spire.
  - Allow only small, refundable or opt-out power boosts.
